# Student Performance Prediction System

## Overview

This project predicts a student's final grade using Machine Learning based on academic performance factors such as study time, attendance, previous grades, and absences.

## Features

- Student Final Grade Prediction
- Machine Learning Model using Random Forest Regressor
- Interactive Streamlit User Interface
- Real\-Time Prediction Results
- Cloud Deployment using Streamlit

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit\-Learn
- Streamlit
- Joblib

## Dataset

Student Performance Dataset

## Machine Learning Model

Random Forest Regressor

## Project Structure

student\-performance\-prediction/

- app.py
- train\_model.py
- requirements.txt
- student\_prediction\_model.pkl
- README.md
- dataset/student\_data.csv

## How to Run

1. Install dependencies:

pip install \-r requirements.txt

1. Run the application:

streamlit run app.py
